Deterministic money controls around probabilistic agents

The agent can recommend and prepare. Global Payment Solutions separately validates identity, authority, limits, recipient, fee, and idempotency before Bridge receives a transfer.

Discover

Read routes, pricing, OpenAPI, or MCP tools.

Draft

Create a payment intent with an idempotency key.

Authorize

Match an owner policy or wait for human approval.

Execute

Submit once to Bridge and track verified webhook status.

Owner authority

Revocable, scoped tokens. Beneficiary allowlists. Per-payment and rolling 24-hour limits. Automatic execution is off by default.

Payment integrity

Each approval produces a short-lived RS256 mandate. Bridge submissions carry a stable idempotency key and a hard-coded 1% fee.

Operational evidence

Every token, policy, draft, approval, execution, and status transition is written to the customer audit trail.

Built for API and MCP clients

Public discovery is unauthenticated. Money movement requires a scoped owner-issued bearer token. Agents cannot create new beneficiaries.

Quote semantics

Quotes are indicative, expire quickly, and are never presented as locked. Bridge determines the executable result at submission.
